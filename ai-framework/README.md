# AI Framework

Osobní produktivitní framework pro práci s podporou umělé inteligence. Jednotný AI framework a znalostní báze (knowledge base) navržená pro použití s nástroji jako Cursor a Claude. Tento framework slouží jako šablona pro pro vlastní projekty.

---

## Přehled

Tento repozitář slouží jako jednotný sdílený AI framework a centrální uzel pro pracovní postupy, standardy kódování a agentní úkoly. Obsahuje pravidla (rules), dovednosti (skills), automatizace (automations) a znalostní bázi (knowledge base) pro zefektivnění vývoje s podporou AI.
